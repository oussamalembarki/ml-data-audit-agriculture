# Audit de Propreté d'un Dataset Agricole

Ce dépôt contient un devoir d'apprentissage automatique consistant à auditer la propreté d'un jeu de données (Dataset) issu de Kaggle.

## 📌 Informations sur le projet
- **Domaine :** Agriculture de précision
- **Dataset :** *Crop Recommendation Dataset* (Kaggle)
- **Outil :** Python (Pandas) sur Google Colab

## 🔍 Objectifs et Résultats de l'Audit
- **Valeurs manquantes :** 0 (Dataset complet)
- **Doublons :** 0 (Lignes uniques)
- **Types de données :** Corrects (`int64`, `float64`, `object`)
- **Valeurs aberrantes :** Aucune anomalie majeure détectée.

**Conclusion :** Le dataset est extrêmement propre et directement exploitable pour entraîner un modèle de Machine Learning.
